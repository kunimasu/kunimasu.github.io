# 利益基準で設計する運用型広告

- 文書の役割：運用型広告の採算、成果観測、広告構造、増額判断を設計するための社内基準です。
- 対象：Google広告などの運用型広告を利用する事業です。
- 起点：不用品回収サービスの改善事例について同僚から受けた助言です。
- 更新日：2026年9月1日
- 検証状態：事例の数値と施策効果の因果関係は未検証です。

## 1. 経営判断としての結論

運用型広告は、広告管理画面に表示される獲得単価ではなく、確定した売上から残る利益を基準に設計します。

この基準を運用へ反映するには、次の四つの判断が必要です。

1. 確定成約1件から残る金額を計算し、許容広告費を決めます。
2. 許容広告費を、実際に入札で利用する成果地点の単価へ換算します。
3. 収益性、検索意図、配信条件が異なる需要だけを分けます。
4. 平均獲得単価ではなく、追加広告費によって増えた利益で増額を判断します。

電話タップやフォーム送信を減らすことが目的ではありません。
広告費を増やした後も、事前に定めた利益が残る状態を作ることが目的です。

## 2. 用語

| 用語 | この文書での定義 |
|---|---|
| **コンバージョン（CV）** | 広告媒体に成果として記録される行動です。電話ボタンのタップ、フォーム送信、購入などが該当します。 |
| **記録CV** | 広告媒体が記録したコンバージョンです。有効な問い合わせや成約と一致するとは限りません。 |
| **有効問い合わせ** | 対象商材、対象地域、連絡可能性など、事前に定めた営業条件を満たす問い合わせです。 |
| **成約** | 顧客が契約または注文に合意した状態です。 |
| **確定成約** | キャンセル、返品、審査否決などを除き、売上と利益の計算対象にできる成約です。 |
| **広告前貢献利益** | 確定成約1件の売上から、広告費以外の変動費を差し引いた金額です。 |
| **管理画面CPA** | 広告費を記録CV数で割った金額です。CPAはCost Per Acquisitionの略称ですが、この文書では分母を明記します。 |
| **有効問い合わせ単価** | 広告費を有効問い合わせ数で割った金額です。 |
| **顧客獲得単価** | 広告費を確定成約数で割った金額です。 |
| **ROAS** | 広告費に対する売上の比率です。Return On Advertising Spendの略称です。 |
| **追加広告利益** | 追加広告費によって増えた確定成約の広告前貢献利益から、追加広告費と追加対応費を差し引いた金額です。 |

「CPA」という語だけでは、電話タップ、有効問い合わせ、確定成約のどれを分母にしているのか判断できません。
会議と報告では、「管理画面CPA」「有効問い合わせ単価」「顧客獲得単価」を使い分けます。

## 3. 許容広告費の計算

### 3.1 確定成約1件当たりの許容広告費

確定成約1件当たりの許容広告費は、広告前貢献利益から、広告費を差し引いた後に残したい利益を引いて計算します。

```text
確定成約1件当たりの許容広告費
= 広告前貢献利益 - 広告費控除後に残したい利益
```

ここで使用する広告前貢献利益には、仕入れや作業原価だけでなく、決済手数料、成約に比例する営業報酬、返金見込みなどの変動費を反映します。
社内の粗利がこれらの費用を含まない場合は、粗利をそのまま計算へ使用しません。

### 3.2 有効問い合わせ単価への換算

広告で直接観測できる成果が問い合わせである場合は、確定成約1件当たりの許容広告費を、有効問い合わせから確定成約に至る割合で換算します。

```text
有効問い合わせ1件当たりの許容広告費
= 確定成約1件当たりの許容広告費
  × 有効問い合わせから確定成約に至る割合
```

確定成約1件当たり3万円まで広告費を使えても、有効問い合わせから確定成約に至る割合が30%なら、有効問い合わせ1件当たりの許容広告費は9,000円です。
問い合わせ単価の目標を3万円にすると、採算を過大評価します。

### 3.3 記録CV単価への換算

電話タップやフォーム送信を入札用の成果として残す場合は、記録CVから有効問い合わせに至る割合も反映します。

```text
記録CV1件当たりの許容広告費
= 確定成約1件当たりの許容広告費
  × 記録CVから有効問い合わせに至る割合
  × 有効問い合わせから確定成約に至る割合
```

問い合わせ対応などの変動費が無視できない場合は、同じ分母に換算して許容広告費から差し引きます。

### 3.4 計算例

次の数値は計算方法を示すために作成した例であり、同僚から共有された事例の実績値ではありません。

| 項目 | 値 | 単位と分母 |
|---|---:|---|
| 確定成約1件当たりの売上 | 100,000 | 円／確定成約 |
| 広告費以外の変動費 | 50,000 | 円／確定成約 |
| 広告前貢献利益 | 50,000 | 円／確定成約 |
| 広告費控除後に残したい利益 | 20,000 | 円／確定成約 |
| 確定成約1件当たりの許容広告費 | 30,000 | 円／確定成約 |
| 記録CVから有効問い合わせに至る割合 | 60 | 記録CV100件当たり60件 |
| 有効問い合わせから確定成約に至る割合 | 50 | 有効問い合わせ100件当たり50件 |
| 有効問い合わせ1件当たりの許容広告費 | 15,000 | 円／有効問い合わせ |
| 記録CV1件当たりの許容広告費 | 9,000 | 円／記録CV |

売上を成果価値にする場合、この例の必要ROASは約333%です。

```text
必要ROAS
= 確定成約1件当たりの売上 ÷ 確定成約1件当たりの許容広告費
= 100,000円 ÷ 30,000円
= 約333%
```

ただし、売上基準のROASは、利益率が異なる商材を同じ基準で比較できません。
複数商材を同じ入札へ含める場合は、売上より広告前貢献利益に近い成果価値を使用します。

## 4. 成果観測の設計

広告媒体が記録する操作と、事業が利益を計上できる状態の間には複数の段階があります。
各段階へ共通の問い合わせ識別子を付け、広告情報と営業結果を対応づけます。

| 段階 | 確認する事実 | 主な用途 |
|---:|---|---|
| 1 | 広告媒体が記録したCV | 計測漏れと媒体別件数の確認 |
| 2 | 電話接続や返信可能な連絡の成立 | 誤操作、未接続、重複の除外 |
| 3 | 有効問い合わせ | 営業対象外の理由と有効率の確認 |
| 4 | 成約 | 営業成約率の確認 |
| 5 | 確定成約 | キャンセル、返品、審査否決の除外 |
| 6 | 広告前貢献利益 | 商材別の利益評価と成果価値の設定 |

自動入札には、利益との関係が確認できる範囲で、できるだけ後段の成果を使用します。
確定成約の件数が少ない場合は、有効問い合わせなどの中間地点を学習用の成果として使用できます。
その場合も、広告施策の最終評価は確定成約と広告前貢献利益で行います。

「通話時間が長い電話は有効」という関係は、実績データで確認するまで仮説です。
通話時間だけを有効問い合わせの定義にすると、短時間で成約条件を確認できる問い合わせを誤って除外する可能性があります。

## 5. 広告構造の分割

広告を分ける目的は、管理画面を整理することではありません。
異なる経済条件または異なる検索意図へ、別の予算、入札目標、広告文、遷移先ページを適用することが目的です。

### 5.1 分割を検討する条件

次の条件のいずれかが実質的に異なる場合は、商材または検索意図を分けます。

- 確定成約1件当たりの広告前貢献利益
- 有効率、成約率、キャンセル率
- 検索意図と広告文
- 遷移先ページ
- 地域、配信時間、予算、入札目標
- 問い合わせへ対応する部署と供給能力

不用品回収であれば、家具や家電、粗大ごみ、遺品、引っ越しに伴う不用品は、収益性と検索意図が異なる可能性があります。
ただし、名称が違うという理由だけでは分割しません。
実績または検証可能な仮説によって、分割後に変える設定を説明できる場合に分けます。

### 5.2 分割する階層

| 異なる条件 | 分割候補 | 理由 |
|---|---|---|
| 予算、入札目標、地域、配信時間 | キャンペーン | 上位の配信制御を別々に設定するためです。 |
| 検索意図、広告文、遷移先ページ | 広告グループなどキャンペーンより下位の単位 | 共通の予算と入札目標を保ちながら、訴求を合わせるためです。 |
| 名称だけが異なり、経済条件と訴求が同じ | 分割しない | 分割による制御上の利益がなく、成果件数だけが分散するためです。 |

分割案には、分ける理由、分割後に変える設定、統合へ戻す条件を記録します。
成果件数が不足して判断が不安定になった場合は、経済条件が近い単位を統合します。
全商材へ共通する固定の件数基準は置きません。

## 6. 広告費を増やす条件

平均CPAは、既存の広告費全体を既存の成果件数で割った数値です。
追加予算で獲得する成果の採算は、平均CPAからは判断できません。

広告費の増額は、追加広告利益で評価します。

```text
追加広告利益
= 追加分の確定成約から得た広告前貢献利益
  - 追加広告費
  - 追加分の問い合わせ対応費
```

増額には、少なくとも次の条件を設定します。

- 追加広告利益が、事前に定めた最低額を上回っています。
- 有効率、成約率、キャンセル率が許容範囲内です。
- 電話応答、営業対応、在庫、作業枠が増加した問い合わせを処理できます。
- 成果計上の遅れを含む観測期間が終了しています。
- 計測方法、価格、営業体制などの比較条件が変わっていません。

停止または再設計の条件も事前に決めます。
追加広告利益が基準を下回った場合、原因を広告配信、問い合わせ品質、営業成約率、供給能力に分けて確認します。

## 7. 不用品回収事例から確定できないこと

共有された事例では、ROASが57%から556%へ改善し、広告費が約3倍へ増えたとされています。
この数値は、成果の大きさを示す主張ではありますが、施策効果の証明ではありません。

次の情報がないため、商材分離、有効CV観測、利益基準の入札が改善原因だったとは断定できません。

- 比較した期間と日数
- 変更前後の広告費、売上、広告前貢献利益の絶対額
- 売上とコンバージョンの定義
- 成果を広告へ帰属させる期間と方法
- 指名検索と指名以外の検索の構成
- 商材、地域、価格、季節性の変化
- 営業担当者、電話応答率、成約率の変化
- キャンセル、返品、対象外問い合わせの扱い
- 広告がなくても発生したと考えられる成約

事例を再利用する場合は、「確認された結果」と「考えられる改善要因」を分けて記載します。
前後比較しかない場合は、改善要因を仮説として扱います。

## 8. 実行手順

### 8.1 採算表を作る

商材ごとに、確定成約1件当たりの売上、広告費以外の変動費、広告前貢献利益、残したい利益、許容広告費を記録します。
問い合わせを成果地点にする場合は、有効率と成約率を使って許容単価を換算します。

### 8.2 計測の対応表を作る

記録CVから確定成約までを同じ問い合わせとして追跡できる状態にします。
無効理由、失注理由、キャンセル理由を選択式で記録し、自由記述だけに依存しません。

### 8.3 現在の広告構造を採算へ対応づける

各キャンペーンと広告グループについて、対象商材、検索意図、遷移先ページ、予算、入札目標、対応部署を確認します。
一つの配信単位に異なる許容広告費が混在している箇所を特定します。

### 8.4 分割と統合を実施する

経済条件または配信制御が異なる単位を分けます。
成果件数が不足し、分割による判断改善よりデータ分散の影響が大きい単位は統合します。

### 8.5 少額の変更で検証する

計測変更、広告構造変更、予算変更を同時に実施すると、改善原因を区別できません。
影響の大きい変更から順に実施し、変更日と対象を記録します。

### 8.6 追加利益を確認して増額する

確定成約と利益が計上されるまでの遅れを考慮して評価します。
増額後に平均値が許容範囲でも、追加広告利益が基準を下回る場合は増額を停止します。

- [ ] 許容広告費を、実際に使用する成果地点の単価へ換算しています。
- [ ] 無効問い合わせとキャンセルを広告評価へ反映しています。

## 10. 会議で使う判断文

> 記録CVを安く増やせるかではなく、確定成約1件から逆算した許容単価で有効問い合わせを増やせるかを判断します。

> 商材を分けるかどうかは商品名では決めません。許容広告費、検索意図、配信制御を変える必要があるかで決めます。

> 広告費を増やせるかどうかは平均CPAでは決めません。追加広告費によって増えた広告前貢献利益で決めます。
