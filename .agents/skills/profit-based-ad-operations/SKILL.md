# 利益基準の広告運用

広告管理画面の数値を改善することと、事業利益を増やすことを区別してください。
広告の評価単位を、計測イベントから確定した売上と利益まで接続してください。

## 最初に確定する情報

商材ごとに次の情報を確認してください。
情報が不足している場合は、数値を推測せず、不明な変数を示したうえで複数の仮定による試算を提示してください。

- 確定成約1件当たりの売上
- 広告費以外の変動費
- 広告費を差し引いた後に残したい利益
- 記録されたコンバージョンのうち、有効問い合わせに該当する割合
- 有効問い合わせのうち、キャンセルや返品を除いた確定成約に至る割合
- 問い合わせ対応能力、在庫、作業枠など、販売量を制限する条件
- 集計期間、コンバージョン計上日、広告の貢献を認める期間

## 採算を同じ分母へ変換する

次の用語を区別してください。

- **記録CV**：広告媒体が記録したコンバージョンです。CVはConversionの略称です。
- **管理画面CPA**：広告費を記録CV数で割った金額です。CPAはCost Per Acquisitionの略称です。
- **有効問い合わせ単価**：広告費を、営業対象になる問い合わせ数で割った金額です。
- **顧客獲得単価**：広告費を、キャンセルや返品を除いた確定成約数で割った金額です。
- **広告前貢献利益**：確定成約1件の売上から、広告費以外の変動費を差し引いた金額です。
- **ROAS**：広告費に対する売上の比率です。Return On Advertising Spendの略称です。

基本式は次のとおりです。

```text
確定成約1件当たりの許容広告費
= 広告前貢献利益 - 広告費控除後に残したい利益

有効問い合わせ1件当たりの許容広告費
= 確定成約1件当たりの許容広告費 × 有効問い合わせから確定成約に至る割合

記録CV1件当たりの許容広告費
= 確定成約1件当たりの許容広告費
  × 記録CVから有効問い合わせに至る割合
  × 有効問い合わせから確定成約に至る割合
```

問い合わせ対応などの変動費が無視できない場合は、同じ分母に換算して許容広告費から差し引いてください。
粗利の定義が社内で曖昧な場合は、粗利という名称をそのまま計算へ使わないでください。

## 成果地点を設計する

計測イベントを次の順序で並べ、各段階の件数と移行率を確認してください。

1. 広告媒体が記録したコンバージョン
2. 実際の連絡成立
3. 有効問い合わせ
4. 成約
5. キャンセルや返品を除いた確定成約
6. 広告前貢献利益

自動入札には、利益との関係が確認できる範囲で、できるだけ後段の成果を使用してください。
後段の件数が少ない場合は、利益との相関が確認できる中間地点を学習用に使い、確定成約と利益を評価用に残してください。
電話タップやフォーム送信を、検証せずに有効問い合わせとして扱わないでください。

## 広告構造を分ける

次のいずれかが実質的に異なる場合に、商材または検索意図を分けてください。

- 許容広告費または広告前貢献利益
- 有効率、成約率、キャンセル率
- 検索意図、広告文、遷移先ページ
- 地域、配信時間、予算、入札目標
- 対応部署または供給能力

予算、入札目標、地域などの制御条件が違う場合は、キャンペーンを分ける候補になります。
検索意図と広告文だけが違い、経済条件を共通にできる場合は、広告グループなどキャンペーンより下位の単位を候補にしてください。
名称が違うだけの商材や、成果件数を失うだけの細分化は避けてください。
分割案には、分ける理由と統合へ戻す条件を併記してください。

## 増額を判断する

平均CPAや平均ROASだけで増額を判断しないでください。
追加広告費によって増えた確定成約の広告前貢献利益から、追加広告費と追加対応費を差し引いて評価してください。

```text
追加広告利益
= 追加分の確定成約から得た広告前貢献利益
  - 追加広告費
  - 追加分の問い合わせ対応費
```

増額前後の比較だけで因果関係を断定しないでください。
計測方法、季節性、指名検索、商材構成、価格、営業体制が変わっていないかを確認してください。
広告以外でも発生したはずの成約を区別できない場合は、広告による増分利益を確定できないと明記してください。

## ROASを扱う

売上基準のROASは、粗利率が異なる商材を同じ価値として扱えません。
商材間で利益率が違う場合は、確定売上ではなく広告前貢献利益に近い値を成果価値として使用する案を優先してください。
売上基準の目標ROASを示す場合は、次の式と前提を併記してください。

```text
必要ROAS
= 確定成約1件当たりの売上 ÷ 確定成約1件当たりの許容広告費
```

## 出力形式

診断または設計結果は、次の順序で提示してください。

1. 経営判断としての結論
2. 確認済みの事実と未確認の仮定
3. 商材別の採算表
4. 計測イベントから確定成約までの対応表
5. 広告構造の分割案と分割理由
6. 増額条件と停止条件
7. 不足データと取得方法
8. 優先順位を付けた実行計画

画面上のCPA低下を、利益改善と言い換えないでください。
事例の前後比較を、比較条件が揃っていないまま施策効果として扱わないでください。
